🏫 School Management System
A simple, modern, and user-friendly school management system built with HTML, CSS, and JavaScript that allows you to add, view, and remove schools effortlessly.

🔗 LIVE LINK : https://schoolmanagesystem.netlify.app/

✨ Features
✅ Add New Schools – Easily add schools with details like name, address, and contact.
✅ Remove Schools – Delete schools with a single click.
✅ Clean & Intuitive UI – Smooth and responsive design for all devices.
✅ Local Storage – Data persists even after refreshing the page.
✅ Search & Filter – Quickly find schools by name or location.

🚀 How to Use
Adding a School
Click the "➕ Add School" button.

Fill in the school details (name, address, contact, etc.).

Hit "Submit" – the school is now saved!

Viewing Schools
📋 All schools are displayed in a clean card layout with key details.

Removing a School
❌ Click the "Delete" button on any school card → Confirm → Done!

🛠️ Installation
No setup needed! Just open index.html in any browser.
